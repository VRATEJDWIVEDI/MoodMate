# 🌸 MoodMate

MoodMate is an interactive web application designed to help users track their emotions, express their thoughts, and receive personalized activity suggestions based on their mood.

---

## 🚀 Features

- 🎭 Mood Selection (Happy, Sad, Stressed, Tired, Bored, Angry)
- 🧠 Dynamic Suggestions based on selected mood
- 📝 Journal System (save and view past entries)
- ❤️ Favorites System (save & manage activities)
- 💭 Thought of the Day (random motivational quotes)
- 🎬 Animated UI elements (floating thought box, marquee text, retro styling)
- 🚨 Emergency Help section with quick access resources

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- LocalStorage (for saving data)

## 💡 How It Works

- Users select their current mood
- The app displays a personalized message and suggested activities
- Users can:
  - Save activities to favorites ❤️
  - Write and store journal entries 📝
  - View past entries in a timeline 📖
- Data is stored locally in the browser using LocalStorage
